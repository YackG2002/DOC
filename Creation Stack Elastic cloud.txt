CREATION DU SPACE (Tenant)
- Se Rendre dans kibana sous la section "Spaces" et cliquer sur "create space"
- Remplir les champs "Name", "Description" avec un nom et une descrpition et dans le champ solution view choisir "Classic"
- Choisisr les fonctionnalités à rendre visible dans le menu de navigation elastic (observability, security, Management, ...), puis définir une image pour commment apparait l'espace puis
cliquer sur "create space"
- Créer et attribuer des rôles : Dans la section security -> roles , créer un nuveau role au besoin en y ajoutant son nom et une description respectivement dans les champs "role name" et "role description"
- Ajouter les 'index privileges' pour pour permettre le control et l'acccès à certaines type de donées dans le cluster

-Affecter le/les roles créer à un tenant en le choisisant par son nom , puis définir les privilèges pour chaque groupe de fonctionnalité (Analytics, Elasticsearch, observability, Sécurity, Management) en les passant sur "All", "None" ou "Read".


CREATION DES AGENTS POLICIES et AJOUT DES INTEGRATIONS

- Dans Management-> Fleet -> Agent policies cliquer sur "Create agent policy" et  entrer un nom et une description
- Définir dans le champ default namespace, une valeur similaire à ce qui à été renseigner pour les roles (doublego)
- Décocher la case ***Collect agent metrics*** puis laisser les autres paramètres avancées par défaut et cliquer sur **Create Agent Policy**.
- Laisser les autres paramètres avancées par défaut et cliquer sur le bouton "Create agent policy"
-Dans **Management -> Fleet -> Agent Policies**, choisir l'agent policy nouvellement créer et cliquer sur **Add Intégration** pour ajouter des intégrations. Donner un nom dans le champ ''integration name'' et décocher (au besoin et si présent dans l'intégration) l'option avancée "Collect metrics from System instances"
- Ajouter (si besoin) l'intégration "Elastic Defend" en prenant le soin, d'activer les options "Malware protections" (Protection level : Detect; Blocklist : actif; Scan files upon modification : désactivé), "Ransomware protections", "Malicious behavior protections" et "Memory threat protections" avec l'option 'Detect' pour le niveau de protection (Protection level) et la case de l'Event "File" décocher dans la section settings

NB: Adopter comme nomenclature pour les intégrations, le nom de l'agent policy suivi de du nom de l'intégrattion (ex: DOUBLEGO System ; pour l'intégration system-1)


-Ajuster le logo de la stack en ajoutant sous Stack Management-> Advanced settings-> Global settings les customs logos du client.
